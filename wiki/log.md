# Wiki Log

This is an append-only log of important wiki activities.

AI agents should add entries when they:

- ingest source evidence
- build or update the wiki
- make design decisions
- file durable query results
- run wiki lint or maintenance passes
- implement target or output slices
- update tests
- sync the wiki after implementation changes
- resolve or add open questions

Use this entry shape:

```md
## [YYYY-MM-DD] operation | Short title

- Summary: ...
- Files changed: ...
- Open questions: ...
```
