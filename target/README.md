# Target Outputs

This folder contains optional implementation work, generated outputs, or pointers to another repository.

Examples:

- migrated application code
- prototype source code
- generated reports or slide decks
- charts, notebooks, or analysis artifacts
- setup notes for an external target repository

AI agents should not make target changes that depend on source understanding until the relevant wiki pages have been generated or updated from `raw/`.

If the target work lives in another repository, document the repository URL, branch, setup commands, and deployment notes in this folder.
