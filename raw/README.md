# Raw Source Material

This folder contains original source material for the wiki project.

AI agents should treat files in this folder as evidence. They may read these files, summarize them, and cite them in `wiki/`, but they should not edit or rewrite raw source files unless explicitly instructed.

Useful subfolders include:

- `articles/`
- `papers/`
- `books/`
- `transcripts/`
- `screenshots/`
- `images/`
- `exports/`
- `source-code/`
- `documents/`
- `notes/`

For application migration projects, add source app screenshots, workflow captures, database exports, permission screenshots, integration notes, existing documentation, and source code if available.

For small projects, adding files here may be enough. For larger collections, `manifest.md` is an optional source inventory you can use to explain what important files are and why they matter.
