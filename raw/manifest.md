# Optional Source Manifest

Use this file only when a source inventory would help humans or AI agents understand the material under `raw/`.

The LLM Wiki method does not require a manifest. For small projects, the agent can inspect `raw/` directly. For larger projects, messy folders, externally referenced materials, or sensitive sources that cannot be stored directly, this manifest can provide useful context.

For each important source, include:

- path
- title or short name
- source type
- date or version, if known
- author or origin, if known
- why it matters
- known limitations or trust concerns
- related wiki pages, after ingestion

Example:

```md
| Path | Type | Date | Description | Notes |
| --- | --- | --- | --- | --- |
| raw/articles/example.md | article | 2026-06-05 | Overview of the project domain. | Needs follow-up on pricing claims. |
```
