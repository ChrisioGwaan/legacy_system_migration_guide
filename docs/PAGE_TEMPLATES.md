# Page Templates

These are starter shapes for pages an agent may create under `wiki/`. Adapt them to the domain in `AGENTS.md` when needed.

## Source Summary

```md
# Source: [Title]

Status: `source-derived`
Source path: [raw/path]
Source type: [article / transcript / screenshot / export / code / note]
Date/version: [known or unclear]

## Summary

## Key Claims

## Entities And Concepts Mentioned

## Evidence Notes

## Contradictions Or Tensions

## Open Questions

## Related Pages
```

## Concept Page

```md
# [Concept]

Status: `source-derived` / `inferred` / `proposed`

## Definition

## Source-Backed Notes

## Related Concepts

## Contradictions Or Uncertainty

## Source Traceability

## Related Pages
```

## Entity Page

```md
# [Entity Name]

## Description

## Attributes

## Evidence

## Open Questions

## Related Pages
```

## Decision Page

```md
# Decision: [Short Title]

Status: `proposed` / `implemented` / `verified` / `deprecated` / `superseded`
Date: [YYYY-MM-DD]

## Context

## Options Considered

## Decision

## Rationale

## Consequences

## Source Or Wiki Traceability

## Open Questions
```

## Open Question

```md
# Question: [Short Title]

Status: `unclear`
Raised: [YYYY-MM-DD]

## Question

## Why It Matters

## Relevant Sources Or Pages

## Candidate Answers

## Resolution Notes
```
